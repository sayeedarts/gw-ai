THE SCIENCE OF LEARNING FROM DATA

SYSTEMS THAT LEARN FROM INFORMATION.

Machine learning is a branch of artificial intelligence focused on developing algorithms that learn patterns and relationships from data.

Instead of defining every possible decision through fixed instructions, machine learning models identify patterns from examples and use those patterns to make predictions, classifications or other computational outputs.

Its applications include pattern recognition, predictive analytics, classification, clustering and optimisation.

UNDERSTANDING THE LEARNING MODELS

FOUR APPROACHES TO MACHINE LEARNING.

01. Supervised Learning

Learning from labelled datasets where the expected output is known. Applications: classification and prediction using labelled data.

  • Linear Regression & Logistic Regression
  • Decision Trees, Random Forests & Support Vector Machines

02. Unsupervised Learning

Identifying hidden structures and relationships in datasets without predefined output labels. Applications: data grouping, pattern discovery and similarity analysis.

  • K-Means Clustering & Hierarchical Clustering
  • Principal Component Analysis & Dimensionality Reduction

03. Reinforcement Learning

Learning through interaction with an environment using rewards and penalties. Applications: sequential decision-making and optimisation problems.

  • Agent, Environment & State
  • Action, Reward & Policy

04. Deep Learning

A specialised area of machine learning based on multi-layered neural networks. Applications: image analysis, sequence processing and complex pattern recognition.

  • Artificial & Convolutional Neural Networks
  • Recurrent Neural Networks & Transformers

FROM RAW DATA TO TRAINED MODELS.

01

Cleaning, normalising, transforming and preparing datasets.

03

Feature Engineering

Identifying and preparing meaningful input variables for model training.

04

Model Training

Applying selected algorithms to learn patterns from training data.

05

Model Evaluation

Testing model performance using appropriate evaluation metrics and unseen data.

06

Model Deployment

Making validated models available for use within a computational application.

07

Model Monitoring

Monitoring performance and identifying when retraining or adjustments may be required.

THE FOUNDATIONS OF MODEL PERFORMANCE

IMPORTANT MACHINE LEARNING CONCEPTS.

Dataset & Features

Datasets provide the information used to train, validate and evaluate models; features are the measurable characteristics supplied as inputs.

Training & Validation

Training is how a model learns relationships from data; validation evaluates behaviour during development.

Inference & Performance

Inference generates outputs from new inputs; accuracy metrics evaluate how well a model performs its intended task.
